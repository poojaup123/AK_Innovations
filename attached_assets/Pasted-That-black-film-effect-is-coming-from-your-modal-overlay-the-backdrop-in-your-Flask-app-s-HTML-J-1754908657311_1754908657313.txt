That “black film” effect is coming from your modal overlay (the backdrop) in your Flask app’s HTML/JS UI — it’s blocking all clicks because it’s not being removed or hidden when the modal is closed.

Here’s how you can fix it:

---

### **1. Problem**

* The backdrop `<div class="modal-backdrop">` stays in the DOM even after closing the modal.
* Its `z-index` is above your whole page and it has `opacity` making the “black film”.
* JavaScript is not cleaning up the backdrop or is stuck with multiple overlays.

---

### **2. Fix in Bootstrap (if you’re using Bootstrap Modals)**

```javascript
// Close modal and remove backdrop properly
$('.modal').on('hidden.bs.modal', function () {
    $('.modal-backdrop').remove(); // remove black overlay
    $('body').removeClass('modal-open'); // restore scroll
});
```

Or if your modal is being opened manually:

```javascript
function closeModal() {
    $('#myModal').modal('hide');
    $('.modal-backdrop').remove();
    $('body').removeClass('modal-open');
}
```

---

### **3. If Using Custom Modal**

Your backdrop is probably something like:

```html
<div id="overlay" class="overlay"></div>
```

CSS:

```css
.overlay {
    position: fixed;
    z-index: 9998;
    background: rgba(0,0,0,0.5);
    width: 100%;
    height: 100%;
    top: 0;
    left: 0;
}
```

JS to hide:

```javascript
function closeCustomModal() {
    document.getElementById('overlay').style.display = 'none';
}
```

---

### **4. Common Prevention**

* Always close *any existing modal* before opening a new one.
* Remove or hide the backdrop on `Cancel` or `X` click.
* Avoid multiple overlays stacking (check z-index values).
