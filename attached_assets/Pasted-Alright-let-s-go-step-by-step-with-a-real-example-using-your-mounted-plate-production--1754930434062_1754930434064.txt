## **Example: Mounted Plate Production with BOM + Batch Tracking + Scrap Tracking**

---

### **1. BOM Setup**

**BOM: Mounted Plate**

| Component Code | Name                  | Qty/Unit | UOM | Notes              |
| -------------- | --------------------- | -------- | --- | ------------------ |
| RM001          | MS Sheet 2mm          | 0.134 kg | KG  | Cutting & Notching |
| PROC001        | Cutting Process Cost  | 1        | JOB | Labor              |
| PROC002        | Notching Process Cost | 1        | JOB | Labor              |
| PROC003        | Zinc Plating          | 1        | JOB | Outsourced         |

🔹 **BOM Details**

* Expected Scrap %: **14%** (historical average)
* Expected Scrap Weight (per sheet): Auto calculated as `(Input weight - Output weight)` from past runs.

---

### **2. Batch Tracking**

**Raw Material Batch**

| Batch Code  | Item Code | Qty (kg) | Location | Purchase Date |
| ----------- | --------- | -------- | -------- | ------------- |
| MS-2025-001 | RM001     | 49.000   | STORE-A  | 2025-08-10    |

---

### **3. Production Run**

We decide to make **Mounted Plates** using **1 sheet** from batch `MS-2025-001`.

**Inputs**

* Raw Material: MS Sheet (Batch: `MS-2025-001`)
* Input Weight: **49.000 kg**
* BOM Output Weight per unit: **0.115 kg**

---

### **4. Output Recording**

After production:

* Total Mounted Plates produced: **365 pcs**
* Total Output Weight: `365 × 0.115 = 41.975 kg`

---

### **5. Scrap Calculation**

Formula:

```
Scrap Weight = Input Weight - Output Weight
Scrap % = (Scrap Weight / Input Weight) × 100
```

Calculation:

```
Scrap Weight = 49.000 - 41.975 = 7.025 kg
Scrap % = (7.025 / 49.000) × 100 ≈ 14.34%
```

---

### **6. Scrap Tracking Record**

**scrap\_tracking table**

| Scrap ID | Batch Code  | BOM Code       | Production Order | Input Weight | Output Weight | Scrap Weight | Scrap % | Scrap Type | Status   |
| -------- | ----------- | -------------- | ---------------- | ------------ | ------------- | ------------ | ------- | ---------- | -------- |
| SCRP-001 | MS-2025-001 | BOM-MNTPLT-001 | PROD-001         | 49.000       | 41.975        | 7.025        | 14.34%  | Offcut     | Reusable |

---

### **7. Inventory Impact**

* **Mounted Plates (FG)**: +365 pcs
* **MS Sheet (RM)**: -1 sheet (49 kg) from batch `MS-2025-001`
* **MS Scrap**: +7.025 kg (New batch `SCRAP-MS-2025-001`)

---

### **8. Flow**

```
[Start Production Order]  
      ↓
[Pick Raw Material Batch: MS-2025-001]  
      ↓
[Use BOM to know input qty per unit]  
      ↓
[Enter Output Qty in Production Form]  
      ↓
[System Calculates Scrap Weight & %]  
      ↓
[Save Scrap Record linked to BOM & Batch]  
      ↓
[Update Inventory: FG+, RM-, Scrap+]  
```

---

### **Why This is Powerful**

* **Batch traceability** — You know exactly which MS sheet batch produced how much scrap.
* **BOM integration** — Scrap % is compared against expected % from BOM.
* **Real-time scrap inventory** — Helps reuse scrap in other jobs or sell it.
* **Process/vendor analysis** — Can see which vendor or process creates most scrap.
