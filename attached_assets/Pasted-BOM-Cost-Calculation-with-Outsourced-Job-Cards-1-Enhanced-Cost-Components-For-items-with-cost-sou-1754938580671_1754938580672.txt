BOM Cost Calculation with Outsourced Job Cards
1. Enhanced Cost Components
For items with cost_source = 'bom_calculated':

Total Item Cost = Material Cost + In-House Labor Cost + Outsourced Job Cost + Overhead
2. Outsourced Job Cost Integration
Job Work Rates Table: Maintain rates for each process type per vendor
BOM Process Costing: Each BOM process can be marked as in_house or outsourced
Vendor-Specific Rates: Different vendors may have different rates for the same process
3. Process Cost Calculation
For each BOM process:

In-House Process: Process Cost = Labor Rate × Time + Machine Cost
Outsourced Process: Process Cost = Job Work Rate × Quantity + Transportation
4. Multi-Vendor Scenario
Primary Vendor: Default vendor for each outsourced process
Rate Comparison: System can compare costs across multiple vendors
Vendor Selection: Choose vendor based on cost, lead time, or quality
5. Dynamic Cost Updates
The system should recalculate when:

Job work rates change for any vendor
Process allocation changes (in-house ↔ outsourced)
Vendor selection changes for a process
Transportation costs are updated
6. Job Card Cost Tracking
Estimated vs Actual: Compare BOM-calculated cost with actual job card costs
Variance Analysis: Track cost overruns or savings
Vendor Performance: Monitor actual costs vs quoted rates
7. Cost Rollup Flow
Raw Materials (purchased) → Manufacturing Processes (in-house/outsourced) → Finished Goods
     ↓                              ↓                                      ↓
Manual Pricing              Job Work Rates + Labor Rates           BOM-Calculated Cost
8. Integration with Existing Job Work System
Your current job work system already tracks:

Process types (Cutting, Bending, Welding, etc.)
Vendor assignments
Quantity sent vs received
Rate per unit
The BOM costing would leverage this existing data structure for accurate cost calculations.
